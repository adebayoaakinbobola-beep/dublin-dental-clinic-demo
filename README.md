# Dublin Dental Clinic

A premium, responsive dental website concept for **Dublin Dental Clinic** in Dublin 1, Ireland. The project combines a modern patient-focused layout with a distinctive 3D-inspired visual presentation.

## Live Demo

https://dublin-dental-clinic-demo.vercel.app

## Project Overview

Dublin Dental Clinic is a front-end portfolio project designed to present a dental practice, its treatments, patient experience, team and contact information in a polished and approachable way. The interface emphasizes clear navigation, strong calls to action and modern visual storytelling.

> **Portfolio note:** This repository is presented as a website concept/demonstration project.

## Key Features

- Responsive design for desktop and mobile devices
- Mobile navigation menu
- Interactive 3D-inspired hero presentation
- Treatment overview with eight service categories
- Practice and patient-care sections
- Team presentation
- Click-to-call and email contact actions
- Clinic address and opening-hours information
- Accessible labels and descriptive image alternative text

## Tech Stack

- React
- TypeScript
- Vite
- CSS
- Tailwind CSS tooling
- Lucide React icons
- Vercel for deployment

## My Contribution

I developed and refined this dental website concept with an emphasis on responsive layout, clear content hierarchy, patient-friendly navigation, modern visual presentation and strong contact pathways.

## Project Goal

The goal of the project is to demonstrate how a dental practice website can combine clear patient information and conversion-focused calls to action with a more premium, contemporary visual identity.

## Run Locally

```bash
git clone https://github.com/adebayoaakinbobola-beep/dublin-dental-clinic-demo.git
cd dublin-dental-clinic-demo
npm install
npm run dev
```

For a production build:

```bash
npm run build
```
